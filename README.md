# [ SYSTEMOS ] — Solo Leveling Career Roadmap & Gamified Productivity Engine

> *"Arise."* — Awaken your professional potential, conquer high-difficulty technical training gates, manage daily quests, and level up your engineering career from absolute zero to Shadow Monarch.

---

## 🌟 Overview

**SystemOS** is a gamified productivity and career development platform inspired by the universe of *Solo Leveling*. It transforms standard career roadmaps, job preparation, and daily developer habits into an immersive RPG interface where every completed task earns XP, ranks up your Hunter profile, and builds production-grade engineering mastery.

---

## 🚀 Key Features

* **Hunter Status & Leveling:** Real-time XP tracking that elevates your rank from E-Rank Hunter all the way to Shadow Monarch as you conquer milestones.
* **Flexible Multi-Track Roadmaps:** Focus on 1, 2, or 3 career paths simultaneously (e.g., Software Engineering, AI Systems, Cloud Architecture) with custom skills, target roles, and guild/company destinations.
* **Absolute Beginner Support (Zero-Skill Mode):** If you are starting from scratch, the system automatically generates an immersive foundational path starting from absolute zero (syntax, logic, and frameworks).
* **Interactive Dungeon Map & Timeline:** Fully responsive DAG graph layout (powered by React Flow and Dagre) charting your path up to the **S-Rank Dungeon** gate, alongside a chronological view.
* **Daily Rotating Training Room:** Time-boxed technical drills with strict scheduling. Complete tasks in time for bonus XP or face gate failure if timers expire.
* **Daily Quests & Bonus Protocol:** Automated daily checklists with persistence penalties for uncompleted tasks and overtime bonus gates.
* **AI Career Strategist Chat:** Integrated tactical guidance to assist with architectural decisions and interview prep.
