## 🌟 Overview

**SystemOS** transforms mundane career roadmaps and task management into a high-stakes hunter leveling simulator. Built for developers, students, and professionals aiming to break into elite tech guilds, it combines interactive graph visualizations, real-time AI strategic counseling, strict daily quest penalties, and bulletproof offline fallback mechanisms to ensure zero downtime during live demonstrations.

---

## 🚀 Key Features

- **🎮 RPG Hunter Status & Ranking:** Earn XP by clearing dungeon milestones and training drills to ascend from an *E-Rank Hunter* all the way to a *Shadow Monarch*.
- **🗺️ Dual Roadmap Views:** Visualize your career path dynamically as a branching React Flow **Dungeon Map** or a structured **Chronological Roadmap** with detailed boss-fight challenges.
- **📅 System Daily & Bonus Quests:** Complete technical routines, manage streaks, and unlock high-difficulty bonus gates (complete with penalty tracking for uncompleted tasks).
- **🤖 AI Career Strategist (`/api/roadmap`):** Integrated AI routing with automatic cascading fallbacks (`Gemini 3.5 Pro` / `Flash-Lite` / `Groq`) and a rock-solid local fallback dataset to guarantee 100% presentation uptime.
- **🔐 Secure Player Authentication:** Fully functional login/awakening protocol with local persistence and a customizable "Remember Me" option.
- **⚔️ High-Difficulty Training Room:** Timed technical drills with live countdown timers, pause/resume controls, and confetti reward integrations for each specific aspect
  

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router) / React
- **Styling:** Tailwind CSS
- **Interactive Graphs:** React Flow & Dagre (for automatic node tree layout calculation)
- **AI Integration:** Google Generative AI SDK & Groq SDK
- **Effects & Icons:** Canvas Confetti & Lucide React
- **Persistence:** LocalStorage & Secure Session Management
